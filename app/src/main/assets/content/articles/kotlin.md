# Kotlin: фундамент Android-разработки

## Null-safety

Kotlin устраняет проблему NullPointerException на уровне типов. Тип делится на два мира:

```kotlin
var a: String = "ok"    // никогда не null
var b: String? = null   // может быть null
```

Инструменты работы с nullable:

- **Safe call** `user?.name` — вызов только при не-null, иначе `null`.
- **Elvis** `?:` — значение по умолчанию: `val name = input ?: "Гость"`.
- **Non-null assertion** `!!` — принудительный каст; при `null` бросает NPE. Используйте только при полной уверенности.
- **Safe call в цепочках** `a?.b?.c` — цепочка прерывается на первом `null`.
- **let** — «сделать что-то, только если не null»: `user?.let { send(it) }`.

Компилятор выполняет **smart cast**: после `if (x != null)` или `is`-проверки переменная автоматически считается non-null/типа. Smart cast не срабатывает для публичных `var` и свойств с пользовательским геттером — там нужен `val` или локальная копия.

## val / var и иммутабельность

`val` — ссылка только для чтения, `var` — можно переприсвоить. Важно понимать: `val` не делает объект неизменяемым. `val list = mutableListOf(1,2)` позволяет `list.add(3)`. Настоящая иммутабельность — `listOf(...)`, строки и data class без изменяемых полей. Иммутабельность — первый фундаментальный принцип потокобезопасности.

## Функции

- Объявляются на верхнем уровне или внутри классов; функции первого класса (передаются как значения).
- **Лямбда** `{ it * 2 }`, **ссылка на функцию** `::foo`, **анонимная** `object : Interface {}`.
- **Высшего порядка**: `list.map { it * 2 }`, `filter`, `forEach`, `fold`.
- **Inline** — вставляет тело в место вызова: убирает аллокации лямбд и открывает non-local return.
- **vararg** и **spread `*`** — переменное число аргументов.
- **Расширения** `fun String.isEmail(): Boolean` — статический вызов с receiver; невиртуальны, без доступа к приватным членам.

## Scope-функции

| Функция | Контекст | Возвращает | Типичный кейс |
|---------|----------|------------|----------------|
| `let`    | `it`     | результат лямбды | безопасное использование nullable |
| `run`    | `this`   | результат лямбды | вычисление с объектом |
| `with`   | `this`   | результат лямбды | группировка вызовов к объекту |
| `apply`  | `this`   | receiver | настройка/инициализация |
| `also`   | `it`     | receiver | побочные эффекты (лог) |

## ООП

- Всё **final по умолчанию**; наследование — через `open`/`abstract`.
- **Интерфейсы** с полями и реализацией методов (с 1.4).
- **data class** — генерирует `equals/hashCode/toString/copy/componentN`.
- **sealed class** — фиксированный набор подтипов → исчерпывающий `when`.
- **enum** — константы-синглтоны с методами и свойствами.
- **object** — синглтон; **companion object** — замена static.
- **Делегаты**: `by lazy { }`, `by SharedPreferences`, пользовательские `getValue/setValue`.

## Типы и generics

- **Any** — верхний тип, **Nothing** — тип без значений (функции, всегда бросающие исключение).
- **Дженерики** стираются в рантайме (type erasure): `is T` и `T::class` недоступны.
- **reified + inline** — обход стирания: `inline fun <reified T> parse(s: String): T`.
- **Вариантность**: `out` (ковариантность, только выдача — как `List<out T>`), `in` (контрвариантность), звёздочный проекция `*`.

## Collections

- Read-only (`listOf`) vs mutable (`mutableListOf`) — тип vs реализация.
- Операции: `map`, `filter`, `flatMap`, `groupBy`, `sortedBy`, `fold`, `associate`.
- **Sequence** — ленивый конвейер без промежуточных коллекций; выигрывает на больших данных при 3+ операциях.

## Ключевые правила для собеседования

1. `val` ≠ неизменяемый объект — это неизменяемая ссылка.
2. `==` — equals, `===` — ссылки.
3. `if`, `when`, `try` — выражения со значением.
4. Extensions не переопределяются — диспетчеризация статическая.
5. `lateinit` — «позже», `lazy` — «при первом обращении, один раз».
